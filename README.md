# Мехай

Рабочее место механика автопарка. Механик выбирает машину, видит результаты диагностики, сверяет рекомендацию со страницей руководства и согласует заявку перед передачей в ТОиР. Сменщик может продолжить работу по той же машине.

[Открыть демонстрационный стенд](https://kartracers.ru/mehay/)

Репозиторий содержит исходный код приложения. Руководства производителей и комплект диагностической системы загружаются отдельно при развёртывании. Для доступа к материалам используется серверное окружение.
